# Decade Data-Sourcing Plan

## Goal

Populate year files and local thumbnails decade-by-decade with parallel agents, while keeping output consistent with the current 1973 format and minimizing merge conflicts.

## Target Output Per Year

Each completed year must include:

- `src/data/years/YYYY.ts`
- `public/images/years/YYYY/*.webp`
- top-of-file source comments for the chart ranking
- `Song[]` entries matching the current repo contract:
  - `rank`
  - `title`
  - `artist`
  - `album`
  - `youtubeVideoId`
  - `imageSelection`
  - `imageSources`
  - `thumbnailPath` via `getSongThumbnailPath`

## Division Of Work

Assign one decade per agent:

- Agent 1: 1940s (`1940-1949`)
- Agent 2: 1950s (`1950-1959`)
- Agent 3: 1960s (`1960-1969`)
- Agent 4: 1970s (`1970-1979`)
- Agent 5: 1980s (`1980-1989`)
- Agent 6: 1990s (`1990-1999`)
- Agent 7: 2000s (`2000-2009`)
- Agent 8: 2010s (`2010-2019`)
- Agent 9: 2020s (`2020-current`)

If fewer agents are available, combine adjacent decades, but never split a single year across agents.

## Merge-Safe Ownership

To keep parallel work clean, decade agents own only:

- `src/data/years/YYYY.ts` for their assigned years
- `public/images/years/YYYY/` for their assigned years

Decade agents should not edit shared registry files during sourcing:

- `src/data/index.ts`
- UI components
- shared types

One integrator agent handles shared-file updates after decade branches are ready.

## Source Rules

Use this priority order for chart ranking:

1. Australian year-end singles chart source with explicit ranking
2. Australian chart book / archive source cited by a stable secondary source
3. Wikipedia only when the page clearly cites the underlying chart source

Use this priority order for images:

1. Album or single artwork
2. Release artwork variant from the same song/release family
3. Artist image only when no acceptable release artwork is available

Use this priority order for YouTube:

1. Official audio or official video for the exact song/version
2. Artist-topic upload
3. Best canonical upload matching the charted version

## Standard Year Workflow

For each assigned year:

1. Find the authoritative year-end top 10 for Australia.
2. Create `src/data/years/YYYY.ts` by copying the 1973 structure.
3. Add one source comment block at the top naming the chart source.
4. For each song, fill all required fields.
5. Prefer album art in `imageSources.album`; set `imageSources.artist` only when needed as fallback.
6. Set `imageSelection` to the asset expected to succeed when `pnpm cache:images YYYY` runs.
7. Generate thumbnails with `pnpm cache:images YYYY`.
8. Confirm `public/images/years/YYYY/` contains one `.webp` per song.
9. Run `pnpm check`.

## Required Formatting Rules

Each year file should follow the same pattern as 1973:

- local `const year = YYYY`
- local `getSong` helper returning `thumbnailPath`
- songs ordered by `rank`
- one song object per chart position
- short comment only when fallback/image nuance matters

Thumbnail rules are fixed and should not be re-decided per decade:

- output path: `/images/years/YYYY/{rank}-{slug}.webp`
- generated by `scripts/cache-images.ts`
- album image attempted first, artist image fallback second
- output size/compression stays owned by the script, not hand-tuned per file

## Acceptance Criteria Per Decade

A decade is complete only when:

- every year file for the decade exists
- every song entry has `youtubeVideoId`
- every song entry has at least one valid image source
- every year has generated `.webp` thumbnails committed
- `pnpm check` passes on the branch
- no shared files were edited except by the integrator

## Integrator Workflow

After one or more decade branches are ready, the integrator agent:

1. merges or cherry-picks the decade branches
2. updates `src/data/index.ts` to register newly added years
3. runs `pnpm check`
4. resolves any duplicate year or registry conflicts

## Agent Prompt Template

Use this prompt shape when handing off a decade:

> Source all Australia top-10 songs for the `<DECADE>` decade using the existing `1973.ts` format. Create only `src/data/years/YYYY.ts` files for your assigned years and `public/images/years/YYYY/` thumbnails for those years. Do not edit shared registry or UI files. Use album art first, artist image only as fallback, generate thumbnails with `pnpm cache:images YYYY`, and finish with `pnpm check`.

4. 2000s
